A tiny Python program that writes one short pickup line an AI agent could say out loud: a machine's twist on the classic "Are you...?" line, charming and flattering, short enough for one breath. Run it and it writes the line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
